# Градиентная студия

Генератор градиентов в браузере. Открыть: https://aidarkhusnutdinov.github.io/gradient-studio/

Для телефона открывайте сайт в Safari или Chrome. Кнопка «Скачать PNG» передаёт изображение браузеру; место сохранения зависит от браузера.

Сайт работает без сборки и сервера приложений. GitHub Pages публикует `index.html` и изображения из ветки `main`.
